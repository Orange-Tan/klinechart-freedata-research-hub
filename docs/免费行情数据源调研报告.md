# 免费行情数据源调研报告

> 调研日期：2026-09-08（关键接口均经本机实测验证）
> 目的：为「K 线图开源库综合对比平台」后续接入新数据源（A股 / 美股 / 加密货币 / 期货 / 基金）做选型准备。
> 标注约定：【实测】= 2026-09-08 本机 curl / 浏览器直接请求验证；【文献】= 官方文档 / AkShare 源码核实；未标注 = 通用知识整理，接入前需复验。

## 〇、项目对接背景（新数据源接入最小流程）

### 统一协议与扩展点

| 位置 | 内容 |
|---|---|
| `src/types/ohlcv.ts` | `OHLCV { time(ms), open, high, low, close, volume }` 全项目统一协议；`KlineDataSource` 接口：`fetchKlines(symbol, period, limit)` + 可选 `subscribe(symbol, period, onUpdate)` |
| `src/data/index.ts` | `dataSources` 注册表 —— 新增源在此注册即出现在 UI 下拉框 |
| `src/data/binance.ts` | 现有实现范式：浏览器直连 + 2s 轮询模拟实时 + generation 竞态守卫 |

**接入一个新数据源的最小步骤**：① 新建 `src/data/<id>.ts` 实现 `KlineDataSource`；② 在 `src/data/index.ts` 注册；③ 处理周期映射（各源周期常量不一致）；④ 时间戳统一转毫秒、字段统一 `Number()` 转数字、排序统一**升序（旧→新）**；⑤ 测试（`npx tsc --noEmit` + Playwright 冒烟）。

### CORS / 代理总览（本项目是纯前端 Vite React）

| 方案 | 适用源 | 说明 |
|---|---|---|
| **浏览器直连（CORS 开放）** | Binance、OKX、Bybit、Gate、HTX、Bitget、**东财 push2his/push2delay**、**腾讯 web.ifzq/qt.gtimg**、Alpha Vantage、Twelve Data、SEC EDGAR | 无需自建服务，最省事 |
| **JSONP 绕过 CORS** | 新浪日K/分钟K（`jsonp.php`） | 用 `<script src>` 注入 + 回调，现代 fetch 不行；GBK 需转码 |
| **需本地代理 / BFF** | Yahoo（无 CORS 头）、新浪（无 CORS + 需 Referer）、天天基金（无 CORS）、Kraken（无 CORS）、各交易所官网（无 CORS）、Tushare | Vite dev 配 `server.proxy`（如 `/yh` → `query1.finance.yahoo.com`）零成本解决；生产用同域后端 / serverless 转发 |
| **纯 Python / 服务端** | AkShare、Baostock、qstock、efinance、CCXT | 前端无法直连；价值在于「接口字典」——照抄其底层 HTTP 接口，或后端起 Python 服务 |

**Key 管理**：免费 token（Twelve Data / Alpha Vantage / Finnhub / Tushare）在浏览器请求 URL 必然可见，个人演示可接受；用 `import.meta.env.VITE_XXX` 注入 + `.env.local` 进 `.gitignore`，**不要提交仓库**。

### 1. 东方财富（主源推荐）【实测】

- **维护方**：东方财富，非官方公开接口，社区广泛使用（AkShare / efinance 均以此为数据源），无需 token。
- **历史 K 线**：`https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.600000&fields1=f1..f6&fields2=f51..f58&klt=101&fqt=0&beg=..&end=..&lmt=..`
  - `secid`：沪市 `1.<code>`、深市 `0.<code>`；指数同理（上证 `1.000001`）。
  - `klt`：1/5/15/30/60 分钟、101 日、102 周、103 月。
  - `fqt`：0 不复权 / 1 前复权 / 2 后复权。
  - 返回 `data.klines` 每根：`日期,开,收,高,低,量(手),额(元),振幅[,涨跌幅,涨跌额,换手率]`。
- **实时快照**：`https://push2.eastmoney.com/api/qt/stock/get?...` 会 302 到 `push2delay.eastmoney.com`（免费延时 ~15 分钟档）。
- **全市场列表**：`push2delay.eastmoney.com/api/qt/clist/get?fs=m:0+t:6,...` 返回全部 5911 只 A 股【实测】。
- **历史深度**：日线上市以来全量（`lmt` 可拉全，接口有 `dktotal` 总数）；1 分钟线仅近 5 个交易日。
- **CORS**：`push2his` / `push2delay` 均【实测】返回 `Access-Control-Allow-Origin: <请求 Origin>` + `Allow-Credentials: true`，**浏览器可直连**。
- **坑**：无 token 但限流明显——连续高频触发长时间 HTTP 000（SSL 断连 / IP 临时封禁）；`push2delay` 相对稳定。**务必限频 ≥2s + 失败退避**，出错降级 `push2delay`。
- **字段单位**：价格、额 = 元；量 = 手；实时快照价格字段为**整数×100**（`/100` 还原）。

### 2. 腾讯财经（降级通道）【实测】

- **实时**：`https://qt.gtimg.cn/q=sh600000,sz000001`（GBK，批量多股），返回 30+ 字段（现价/昨收/今开/量/买卖盘/涨跌幅%等）。
- **历史 K**：`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600000,day,起,止,数量,qfq`；分钟 `https://ifzq.gtimg.cn/appstock/app/kline/mkline?param=sh600000,m5,,320`。
  - 日/周/月每根 `[日期,开,收,高,低,量(手)]` 6 列，**无成交额、无涨跌幅**；复权键名 `qfqday`/`hfqday`，不复权 `day`。
  - 分钟每根 `[YYYYMMDDHHMM,开,收,高,低,量,{},涨跌幅%]`。
- **历史深度**：日线上市以来全量（浦发 1999-11-10 起约 6600 根），**每页 ≤800 根滚动拉取**；分钟线单次最多 320 根。
- **CORS**：`access-control-allow-origin: *`【实测】，**浏览器可直连**；返回 GBK，需 `TextDecoder('gbk')` 转码。
- **坑**：前复权早期价格可能为负（浦发 1999 年前复权 -2.5 元，需过滤或转不复权）；服务器偶发 301 到 `web3.ifzq`（web3 偶发 SSL 断连，用 `web.ifzq` 稳定）。

### 3. 新浪财经（快照补充源）【实测】

- **实时**：`https://hq.sinajs.cn/list=sh600000,sz000001`（GBK）。**2022 年后必须带 `Referer: https://finance.sina.com.cn` 否则 403**；无 CORS 头，浏览器直连被拦。
- **历史日K**：`https://quotes.sina.cn/cn/api/jsonp_v2.php/.../CN_MarketDataService.getKLineData?symbol=sh600000&scale=240&datalen=N`。含 day/open/high/low/close/**volume(股)**，**无成交额、无涨跌幅、无复权**；单次最多约 1950 根（约 8 年），分页需按日期滚动。
- **坑**：隐性限流强、频繁请求易封 IP；GBK 编码；返回 `location.href` 跳转壳需过滤。适合秒级实时快照，不适合主 K 线源。

### 4. Baostock【实测】

- Python 库（`pip install baostock`），底层自有 TCP 行情服务器。**免费、无需注册、无 token**。
- `query_history_k_data_plus` 返回 date/open/high/low/close/volume/amount/pctChg，**支持前/后复权**；日线上市以来全量；5/15/30/60 分钟可取【实测】；指数可取。
- **无实时盘中**；服务端长期无人维护（失效风险最高一档），但 2026-09-08 实测仍可用、数据与东财一致。
- 浏览器无法直连（Python 库），只适合后端方案。

### 5. Tushare Pro【文献】

- 需注册 token，**积分门槛制**（调用不消耗积分）。注册送约 100 分；日线 `daily` 最低 120 分（仅**不复权**）；复权/分钟/财务需 2000+ 分（约 200 元/年）。积分一年有效期。
- 120 分档：50 次/分、8000 次/日；日终更新；数据最稳但免费档逐年收紧。
- **CORS 受限，浏览器无法直连**，必须后端代理。对纯前端演示项目偏重，不推荐。

### 6. AkShare【文献】

- Python 库（MIT，22.5k stars），本质是对东财/新浪/腾讯网页接口的爬虫封装。无需注册。
- `stock_zh_a_hist`（东财日线）支持 qfq/hfq 复权；`stock_zh_a_hist_min_em` 1 分钟仅近 5 个交易日。
- **对本项目最大价值是"接口字典"**：它封装的底层 HTTP 接口（东财 push2his 等）可直接被前端复用，不必依赖 Python。
- 新浪源已被官方标注"建议切换为东财源"；接口随时可能因源站改版失效。

### 7. 上交所 / 深交所官网【实测】

- 上交所 `www.sse.com.cn` / `query.sse.com.cn` 本环境不可达（疑似风控）；官方 JSONP 需 Referer 且有反爬。**不推荐**。
- 深交所官网可达，但行情 API 返回空/50x；提供日行情 Excel/CSV 文件下载（全市场每日一次，延时约 1 天）。**适合历史全市场文件批处理，不适合演示主源**。

### 8. 同花顺 / 问财【实测】

- **iFinD**：免费仅面向高校师生（院校授权），个人需付费。不推荐。
- **问财**：`get-robot-data` 实测返回 401，需登录态 + 复杂签名，反爬极强。仅适合人工选股，不适用。

### 9. 其他轻量方案

qstock、easyquotation、adata 等均依赖同一批网页接口，**不如直接接东财/腾讯原始接口**，无增量价值。

### A股接入要点

- 主源东财 + 备源腾讯双轨：前端封装 `getKlines()` + `subscribeLive()` 门面，东财限流时自动降级腾讯。
- 周期映射：项目 `KlinePeriod` → `klt`（日=101、5分=5、15分=15、60分=60）；`time` 用 `YYYY-MM-DD` 字符串转毫秒。
- 实时订阅对标现有 Binance 2s 轮询 + generation 竞态守卫模式；**务必限频**（实测东财高频触发 SSL 断连）。

## 三、美股数据源

### 推荐度排序

| 排序 | 数据源 | 浏览器直连 | 免费配额 | 历史深度 | 说明 |
|---|---|---|---|---|---|
| 1 | **Twelve Data** | ✅ `*` | 8 credits/分、800/天 | 日线+分钟线 | 免费档仅个人内部非展示用途 |
| 2 | **新浪财经美股日K** | ⚠️ JSONP | 免 token | 1984 年至今全历史 | 无 CORS，可用 `<script>` 绕过 |
| 3 | **Yahoo Finance chart** | ❌ 需代理 | 免 token | 日线 40+ 年、1m 近 7 天 | 数据最全，需 Vite proxy |
| 4 | Finnhub | ✅ | ~60 次/分 | 约 5 年日线 | 免费档限额需注册后复核 |
| 5 | Alpha Vantage / Polygon(Massive) / Tiingo | ✅ | 25次/天 / 5次/分 / 50次/时 | 20年 / 2年 / 30年 | 配额过紧，仅演示级 |

### 1. Yahoo Finance（数据最全，需代理）【实测】

- 逆向接口（官方已停发 key）。`https://query1.finance.yahoo.com/v8/finance/chart/{symbol}` 当前【实测】免 crumb/cookie 直接返回。
- 覆盖美股全标的、指数（`^GSPC` 实测可用）、ETF、ADR；含 `adjclose` 调整价。
- **历史深度**：日线 `range=max` 返回 1984-12 至今【实测】；1m 分钟线仅约 7 天，1h 约 730 天。
- **CORS**：❌ 响应无 `Access-Control-Allow-Origin`，浏览器直连被拦，**必须后端代理**。
- 坑：ToS 仅限个人使用，商业展示有合规风险；长期高频会被 429。

### 2. Alpha Vantage【文献】

- 需免费注册 key。**免费档现为 25 次/天**（2026 年官方 support 页确认，历史曾 500 次/天，已大幅收紧）。
- 日线全量约 20 年 + `ADJUSTED` 拆分/股息调整；分钟线端点存在但**免费档不支持**。
- CORS `*` 可直连，但 key 暴露在 URL；25 次/天对本项目换 symbol/周期太紧张。不推荐为主源。

### 3. Finnhub【文献】

- 免费注册 key；`stock/candle` 支持 1/5/15/30/60/D/W/M，OHLCV 齐全；免费档约 5 年日线、约 60 次/分（社区说法，未复核）。
- 支持 CORS。免费档 WebSocket 有限。备选。

### 4. Twelve Data（主推）【实测】

- 免费注册 key（demo key 可用）。**免费 Basic：8 credits/分、800 credits/天**；WS 8 条试用。
- 日线 + 分钟线（1/5/15/30/60min）OHLCV；无拆分调整字段（未调整价）。
- 单次 `outputsize` 上限 5000 根。
- **CORS `*`【实测】可直连**。
- 坑：ToS 免费层仅**个人内部非展示**用途；key 用 `.env` 注入不进 git。

### 5. Polygon.io（已更名 Massive）【文献】

- 2025-10-30 更名 Massive.com，`polygon.io` 301 到 `massive.com`，账号/API 无缝沿用。
- **免费档：5 次/分、仅 2 年历史**、EOD + minute aggregates、美股 100% 覆盖；实时需付费。
- 5 次/分对 4 库同步拉取会撞限，不推荐主源。

### 6. Tiingo【实测】

- 免费 Starter：**50 次/时、1000 次/天**、500 唯一 symbol/月、**30+ 年历史**；含 EOD（adj/divCash/splitFactor）、IEX 实时源。
- 【实测】带 Origin 请求返回 403（无 CORS 头），直连受限，建议代理。50 次/时对 4 图轮询偏紧。

### 7. Stooq【实测】

- 曾经最省事的免费源，**2026 年起已加 JS 反爬验证墙**（PoW challenge），curl 与浏览器直连都拿不到 CSV。**已不可直连**，不推荐。

### 8. IEX Cloud —— **已停服，排除**【文献】

- 2024-08 起停止运营，官方页面 "IEX Cloud has retired"。不用接入。

### 9. Nasdaq Data Link / Quandl【文献】

- 美股 EOD 日线全为 Premium（付费）；WIKI 免费数据集早已退役；免费数据多为宏观/政府/CFTC。**不适合 K 线**。

### 10. 中文免注册接口【实测】

| 接口 | 实测结果 |
|---|---|
| 腾讯实时报价 `qt.gtimg.cn/q=usAAPL,usMSFT` | ✅ 返回 ~ 分隔字段，**CORS `*`**，GBK 编码 |
| 腾讯美股日K `web.ifzq.gtimg.cn/.../usfqkline/get` | ⚠️ 仅返回 2 根（疑似改版/限流），**不可靠，勿作历史源** |
| 新浪实时 `hq.sinajs.cn/list=gb_aapl` | ✅ 需带 Referer，否则 403；无 CORS 头 |
| 新浪美股日K `US_MinKService.getDailyK?symbol=aapl` | ✅ **10026 根，1984-09-07 至今**，全历史日线 OHLCV+量，JSONP + GBK |
| 新浪美股分钟K `US_MinKService.getMinK?type=1/5/15/60` | ✅ m1≈3 交易日、m5≈13 交易日、m15≈2 个月、m60≈7 个月 |

- 新浪全系无 CORS 头，但日K/分钟K 是 **JSONP 格式**，可用 `<script src>` 注入绕过 CORS（GBK 需转码、需过滤防盗链前缀）。
- 稳定性中等，无 SLA，适合做长历史兜底。

### 11. 富途 / 老虎开放平台【文献】

- 需券商开户 + 本地 **OpenD 网关**（桌面应用 protobuf/WS），非纯 REST；K 线走额度制。**与纯前端浏览器项目不匹配，排除**。

### 美股接入要点

- 免费美股源大多是**日终 / 15 分钟延时**（除 Twelve Data 实时美股），本项目美股端按"延时演示"接入即可，不要承诺实时。
- 首选链路：**Twelve Data（直连）** 作主源，**新浪美股日K（JSONP）** 作长历史兜底；要指数/ETF/ADR 全量就加 **Yahoo（代理）**。
- 时间戳：Yahoo 是秒（`/1000`）；新浪/腾讯是字符串 + GBK 编码（前端需转码）。

### 1. Binance（已在用）【实测确认】

- 无 key、CORS `*`、`/api/v3/klines` 权重=2、**6000 weight/分钟/IP**；单次 `limit` 最大 1000（默认 500）；16 档间隔（1s~1M）；时间戳毫秒、**升序**；WS `kline_1m` 增量推送。
- 超限返 429，继续封 IP（2 分钟~3 天递增）；需退避重试。
- 行情 API 本身不设地区鉴权（大陆直连可用），但官方对受限地区不提供服务。

### 2. OKX（推荐第二源）【实测】

- 无 key。REST `www.okx.com/api/v5/...` + WS。K线：`/market/candles`（最近）+ `/market/history-candles`（历史回溯）。
- **单次 `limit` 最大 300【实测】——与本项目 `HISTORY_LIMIT=300` 完美对齐，一次拉满**。
- 间隔 1m~3M（**1 小时及以上用大写：1H/4H/1D**，坑）；返回**降序**需 `reverse()`；毫秒时间戳。
- CORS【实测】回显 origin 可直连；限流宽松（连发 40 次无 429）。
- 中文文档完善；美国/澳洲用户须用 `us.okx.com`。

### 3. Bybit（推荐第三源）【实测】

- 无 key。REST `api.bybit.com/v5/market/kline`（spot/linear/inverse 用 `category` 区分）+ WS。
- 间隔 1,3,5,15,30,60,120,240,360,720,D,W,M；单次 `limit` 最大 **1000【实测】**（W 档约 271 根）。
- 速率：**600 请求/5 秒/IP**，超限 403 且提示停止 10 分钟。
- CORS【实测】回显 origin + credentials；降序、毫秒；中文文档完善。

### 4. Gate.io【实测】

- 无 key。`api.gateio.ws/api/v4/spot/candlesticks`；单次最大 1000；间隔含 10s~30d。
- CORS `*`【实测】。**返回时间戳秒 + 字符串数组、升序、带 `isClosed`**，需 `/1000` + `Number()`。

### 5. HTX（原火币）【实测】

- 无 key。`api.huobi.pro/market/history/kline`；**单次 size 最大 2000【实测】——深度最大**；秒级时间戳、升序。
- 品牌/合规问题较多（多地受限），作第三源谨慎；可作深历史补充。

### 6. Bitget【实测】

- 无 key。`api.bitget.com/api/v2/spot/market/candles`；granularity 拼写是坑（**小写 `1min`/`1h` 而非 `1m`**，实测传 `1m` 报 400）；单次最大 1000；降序、毫秒。另有 `/history-candles` 深回溯。

### 7. Kraken【实测】

- 无 key。`/0/public/OHLC` 间隔 1/5/15/30/60/240/1440/10080/21600；**每次固定返回 721 根**。
- **❌ 响应无 CORS 头【实测】，浏览器直连被拦，必须服务端代理**。交易对命名特殊（BTC→XBT、USD→ZUSD）。

### 8. CoinGecko / CoinMarketCap / CryptoCompare / CoinCap

| 源 | 现状 | 结论 |
|---|---|---|
| CoinGecko | 2024 年后必须注册 key（免费 Demo：100 次/分、1 万次/月）；`/coins/{id}/ohlc` 是聚合粒度（≤1天→30分钟档等），**无 1m/5m 逐根K线、无 volume**；无 WS | ❌ 不适合 K 线对比 |
| CoinMarketCap | 免费档收紧向付费迁移；**无交易所 K线**（OHLCV 付费档）；pro-api 需服务端 key | ❌ 不适合 |
| CryptoCompare | 归 CoinDesk；**无 key 实测 401 "API key required"**；免费档近年收紧 | ❌ 不适合 |
| CoinCap | 文档 301 到 pro.coincap.io（登录墙），**公共免费层消失**；`api.coincap.io` 实测不可达 | ❌ 不稳定 |

### 9. ccxt【文献】

- 聚合 100+ 交易所（Binance/OKX/Bybit/Gate/KuCoin/HTX/Bitget…），`fetchOHLCV(exchange, symbol, timeframe)` 统一拉 K 线，公共行情无 key。
- 浏览器端不适用（服务端库、体积大、WS 收费 CCXT Pro）。**适合本项目后续做 "Node 聚合 BFF"**。

### 加密货币接入要点

- 第二源 **OKX**（`limit=300` 一次拉满，CORS 放开）；第三源 **Bybit**（1000 根、CORS 放开）。
- **坑：OKX/Bybit/Bitget 返回降序需 `reverse()`；Gate/HTX 是秒级时间戳 + 字符串；Gate 还要注意大小写区间**。
- 明确不接：CoinGecko（无分钟级K线）、CoinMarketCap（收费）、CryptoCompare（需 key 实测 401）、CoinCap（收费化）、Kraken（无 CORS）。

### 工程落地顺序建议

1. **第一批（纯直连、零代理）**：A股东财 + 腾讯、加密货币 OKX/Bybit —— 无 key、CORS 放开，直接复用现有 `binance.ts` 的 `fetchKlines`/`subscribe`（2s 轮询 + generation 竞态守卫）模式。
2. **第二批（加 Vite dev proxy）**：美股 Twelve Data / Yahoo、期货新浪 RB0 / Yahoo CL=F、场外净值天天基金 —— 统一在 `vite.config.ts` 配一层 `server.proxy`，避免每个适配器重复处理 CORS/Referer/重试。
3. **第三批（特殊形态）**：新浪 JSONP（`<script>` 注入）、SEC EDGAR（持仓，非 K 线）、ccxt 聚合（Node BFF）。

### 通用坑位清单（接入每个源都核对）

1. **时间戳单位**：毫秒（Binance/OKX/Bybit/Bitget/天天基金）vs 秒（Gate/HTX/Yahoo）vs 字符串（东财/新浪/腾讯），统一 `/1000` 或 `Date.parse` 转毫秒。
2. **排序方向**：Binance/Gate/HTX/东财升序；**OKX/Bybit/Bitget 降序需 `reverse()`**。
3. **返回类型**：Binance/东财/OKX 数字或数字字符串；Gate/新浪/腾讯是字符串数组，需 `Number()`。
4. **周期常量不一致**：各源 1h/1d/1W 大小写、数字档位（OKX `1H` 大写、Bitget `1min` 小写、Bybit 纯数字、东财 klt 101）——统一在适配器内做 `Record<KlinePeriod, string>` 映射。
5. **复权**：A股/ETF 建议前复权（`fqt=1` / `qfq`）；早期复权价格可能为负需过滤。
6. **限频与封禁**：东财/新浪高频封 IP；Binance weight 制；Bybit 600/5s；一律退避重试 + 降级源。
7. **编码**：新浪/腾讯实时是 GBK/GB18030，前端需 `TextDecoder('gbk')`。
8. **实时性预期**：A股/加密有真实盘中实时；美股免费源多为日终/15 分钟延时；场外基金净值 T 日晚更新。
