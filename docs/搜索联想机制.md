# A 股股票/指数搜索联想机制

> 本文档说明看板顶部搜索框的联想机制、程序实现与作用。
> 关联代码：`src/pages/Dashboard.tsx`（UI 层）、`src/data/aShareSearch.ts`（搜索核心）、`src/data/tencent.ts` / `src/data/eastmoney.ts`（数据源适配）、`src/types/ohlcv.ts`（`StockResult` / `KlineDataSource.searchSymbols`）。

## 1. 机制一句话

**联想表不是程序本地维护的，而是由第三方搜索 API（东财 suggest / 腾讯 smartbox）现成返回的**；程序只负责：发起请求 → 双源竞速取最快结果 → 过滤非 A 股/指数 → 归一化代码格式 → 渲染下拉。

本地没有内置任何股票代码表，联想能力完全依赖第三方接口。这也是做**双源竞速**的原因：两个接口都有偶发不可用，单源会让搜索框随机失灵。

## 2. 整体数据流

```
输入 ≥2 字符
   │  300ms 防抖（useDebounced）
   ▼
Dashboard effect ── source.searchSymbols(kw)
   │                     │  （可选能力，仅东财/腾讯实现；TDX 空、Binance 无）
   ▼                     ▼
              aShareSearch.searchAStock(kw)
                │  双源竞速：东财先发(1.5s 超时切腾讯) + 9s 兜底总超时
                │  谁先成功用谁
                ▼
          StockResult[]（已过滤 + 归一化 sh/sz+6位）
   │
   ▼
setResults → 下拉渲染（name / symbol / type）
   │
   ▼
点选 pickStock() → 设置 symbol + 名称，清空输入
```

## 3. 三个层次的分工

### 3.1 UI 层 — `src/pages/Dashboard.tsx`

| 部分 | 实现 | 作用 |
|---|---|---|
| 状态 | `query` / `debouncedQuery` / `results` / `searching` | 输入值、防抖值、结果列表、加载中 |
| 防抖 | `useDebounced(query, 300)`（组件内 hook） | 等待 300ms 静默期才发请求，避免每敲一个字打一次 API |
| 搜索 effect | `debouncedQuery` 变化触发 | **关键字 < 2 个字符直接清空结果**；否则调 `source.searchSymbols(kw)` |
| 竞态防护 | effect 内 `cancelled` 标志 | 换词/切源后旧请求返回即丢弃，不污染新下拉 |
| 展示 | `.search-dropdown`（ul） | 每行按钮显示 `name`（加粗）、`symbol`（蓝色）、`type`（右上角徽标） |
| 选择 | `pickStock(r)` | `setSymbol` + `setSymbolLabel` + 清空输入和结果 |
| 键盘 | `Escape` 清空结果 | 快速收起下拉 |

要点：
- 搜索是**数据源可选能力**：`KlineDataSource.searchSymbols?` 为可选方法。只有 `tencent` / `eastmoney` 实现并转调 `searchAStock()`；`tdx` 返回空数组（`src/data/tdx.ts`），`binance` 未实现。
- `useDebounced` 用 `setTimeout` + cleanup 清除实现，卸载时自动取消。

### 3.2 核心 — `src/data/aShareSearch.ts`

**双源竞速逻辑（`searchAStock`）：**

```
eastmoneyPromise = jsonp(东财 suggest, cb, 5s) → parseEastmoney
tencentPromise  = jsonp(腾讯 smartbox, callback, 4s) → jsonpTencent

new Promise((resolve, reject) => {
  9s GLOBAL_TIMEOUT 兜底（超时整体 reject，UI 显示空下拉）
  eastmoneyPromise.then(resolve)   // 谁先成功用谁
  tencentPromise.then(resolve)
  // 先 settle 清计时器；resolve 天然只接受第一个调用
})
```

| 源 | 端点 | 特性 | 解析 |
|---|---|---|---|
| 东财（首选） | `searchapi.eastmoney.com/api/suggest/get` | 200 但**不返回 CORS 头**，浏览器 fetch 被拦 → **必须 JSONP**；`cb` 回调参数 | `QuotationCodeTable.Data[]`；`Classify === 'AStock' \| 'Index'` 保留；`QuoteID` 前缀 `0.`=深 / `1.`=沪 |
| 腾讯（兜底） | `smartbox.gtimg.cn/s3` | 返回 **GBK 编码**文本 `v_hint="sh~000001~上证指数~szzs~ZS^..."` | 按 `^` / `~` 分段；`f[3]` `ZS`=指数 / `GP-A`=股票 |

过滤规则（两源统一）：
- 只保留 **A 股股票（`AStock`/`GP-A`）** 与 **指数（`Index`/`ZS`）**
- **过滤**基金、港股、美股、期货等（东财返回结果里这些类别直接丢弃）
- `symbol` 归一化为腾讯格式：`sh`/`sz` 前缀 + 6 位数字代码，并用 `/^[shz]{2}\d{6}$/` 兜底校验

### 3.3 JSONP 封装（`jsonp<T>`）的两个易踩坑点

1. **回调必须先用显式 `window.xxx` 挂全局，再设置 `script.src`**。
   反过来会踩竞态：本机网络极快时 script 回调先执行，此时 `window[cbName]` 还是 `undefined` → `Uncaught ReferenceError`（代码注释注明"实测复现"）。
2. **回调名不能依赖闭包变量名**。生产构建 terser 会改写变量名，脚本里引用的全局回调名若写成变量会随之改变，回调永远不触发。所以用 `w[cbName] = ...`（`window as unknown as Record<string, unknown>` 桥接，规避 TS7015）显式挂载，`delete w[cbName]` + 移除 script 做清理。

`jsonp` 的 resolve 与 executor 解耦（先保存 `resolveFn` 再建 Promise），避免"回调先于 Promise 构造到达导致 resolve 为 undefined 丢数据"。

## 4. 数据源适配

- `src/data/tencent.ts` `searchSymbols` → `return searchAStock(keyword)`
- `src/data/eastmoney.ts` `searchSymbols` → `return searchAStock(keyword)`
- `src/data/tdx.ts` `searchSymbols` → 空数组（TDX 无搜索能力，UI 静默跳过）
- `binance` 无 `searchSymbols`（可选方法未实现）

统一返回 `StockResult[]`：

```ts
interface StockResult {
  symbol: string; // sh600519 / sz000001（统一腾讯格式）
  code: string;   // 6 位代码
  name: string;   // 名称
  type?: string;  // '股票' | '指数'
}
```

## 5. 交互与样式

- 输入框 `placeholder="搜索 A 股股票/指数"`，focus 时边框变品牌色 `#26a69a`
- 加载中：输入框内右侧显示 `…` 旋转点（`.search-spinner`）
- 下拉 `.search-dropdown`：绝对定位在输入框下方，320px 宽、最大高 300px、溢出滚动，深色浮层（背景 `#161c2c`、描边 `#2b3245`、投影）
- 每行：名称加粗（`#e8ecf3`）、代码蓝色等宽（`#7aa2f7`）、类型徽标靠右（圆角胶囊）
- 结果为空时不渲染下拉

## 6. 可以改的点 / 扩展方向

- **新增数据源接入搜索**：实现 `searchSymbols` 转调 `searchAStock`（或接入自己的搜索 API）即可出现在下拉
- **防抖时长**：`useDebounced(query, 300)` 可调，网络差可加大
- **候选源**：东财 suggest / 腾讯 smartbox 之外的源可加入竞速（`searchAStock` 内继续追加 promise）
- **下拉交互**：目前无键盘上下选择；如需可用 ↑/↓ + Enter 选股
